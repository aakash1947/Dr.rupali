# Dr. Rupali Gupta — Gynaecology website

A responsive React-based clinic website and booking-flow prototype.

## Run locally

1. Use Node.js 22.13 or later.
2. Run npm ci.
3. Run npm run dev.
4. Open the local address shown in the terminal.

## Demo scope

- Clinic overview, doctor introduction, services, educational journal cards, FAQs, patient stories placeholder, and emergency-care note.
- Interactive appointment flow with sample 15-minute slots from 5 PM to 8 PM.
- Patient appointment preview and a clinic schedule preview for weekly availability, consultation window, fee, slot duration, breaks and blocked slots.
- Simulated payment and confirmation. This demo does not charge a patient or send an appointment to the clinic.

## Before clinic launch

The current build is a front-end prototype. It does not save bookings, handle real patient information or medical files, process payments, create video links, send WhatsApp or email messages, or provide secured patient or doctor accounts. The sample fee and availability are illustrative. Connect a clinic-approved booking service, payment gateway, secure storage, video provider, messaging provider, authentication, privacy/consent language, policies, analytics and tracking before accepting real patients. Add Dr. Rupali Gupta’s approved profile photo, qualifications, contact details, clinic address and policy text.
